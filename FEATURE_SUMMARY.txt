⚙️ SYSTEM ARCHITECTURE

  Message View
      ↓ (long-press)
  GestureHandler (500ms detection)
      ↓
  AnimatedReactionPanel.show()
      ↓
  AnimationController creates animations
      ↓ (staggered)
  EmojiImageView[] animate into view
      ↓ (user touches)
  Selection animation plays
      ↓ (user releases)
  Confirmation animation
      ↓
  Reaction callback triggered
      ↓
  Store in message database
      ↓
  UI updates to show reaction

🎬 ANIMATION SEQUENCES

Panel Appear:
  Duration: 300ms
  Scale: 0.8 → 1.0
  Alpha: 0 → 1
  Effect: OvershootInterpolator (smooth bounce)

Emoji Appear (Staggered):
  Per Emoji:
    Duration: 300ms
    Delay: index × 50ms
    Scale: 0 → 1
    Alpha: 0 → 1
    TranslationY: 50dp → 0
    Effect: BounceInterpolator

Selection Animation:
  Duration: 200ms
  Scale: 1.0 → 1.3 → 1.15 (bounce)
  Effect: OvershootInterpolator

Confirmation Animation:
  Duration: 400ms
  Scale: 1.0 → 1.5 → 0.95 → 0 (celebratory)
  Alpha: 1 → 0
  Effect: BounceInterpolator

⚡ QUICK START (5 MINUTES)

1. Add to Layout XML:
   ───────────────────
   <org.thoughtcrime.securesms.reactions.animated.AnimatedReactionPanel
       android:id="@+id/animated_reaction_panel"
       android:layout_width="wrap_content"
       android:layout_height="wrap_content"
       android:visibility="gone" />

2. Initialize:
   ──────────
   val panel = view.findViewById(R.id.animated_reaction_panel)
   panel.configure(ReactionPresets.default)

3. Setup Long-Press:
   ────────────────
   messageView.setOnTouchListener { _, event ->
       when (event.action) {
           MotionEvent.ACTION_DOWN -> {
               handler.postDelayed({
                   panel.show(messageView, messageView)
               }, 500)
           }
           MotionEvent.ACTION_UP -> { /* cancel */ }
       }
   }

4. Handle Selection:
   ────────────────
   panel.setOnReactionSelectedListener { emoji, _ ->
       addReactionToMessage(emoji)
   }

🔧 TROUBLESHOOTING QUICK REFERENCE

Problem                    → Solution
─────────────────────────────────────────
Panel not appearing        → Check visibility, long-press timeout
Emoji not showing          → Verify reactions list has valid emoji
Animation slow/janky       → Reduce animationDuration, enable hardware acceleration
Position off-screen        → Ensure layout constraints, check edge detection
Touch not responsive       → Verify long-press is 500ms
Memory high                → Call cleanup() in onDestroyView()
